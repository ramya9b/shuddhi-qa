Security First

Your keys never leave the server

Both the Claude API key and Azure DevOps PAT are stored as Vercel environment variables. The browser never sees them — not in the source code, not in network requests, not in localStorage.

✓ No API key in browser HTML
✓ No eval() or new Function()
✓ ADO URL allowlist enforced
✓ CORS restricted to Vercel origins
