How to create an ADO PAT →
  1. Open Azure DevOps → click your Profile avatar (top right)
  2. Click User Settings → Personal Access Tokens
  3. Click New Token — set Name, Organisation, Expiry
  4. Scopes: Test Management: Read & Write + Work Items: Read & Write + Project and Team: Read
  5. Click Create → Copy the token immediately
  6. Vercel Dashboard → Project → Settings → Environment Variables
  7. Name: ADO_PAT | Value: paste token → Save → Redeploy
