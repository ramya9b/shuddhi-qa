How to add a key in Vercel →
  1. Get your free API key from the provider link above
  2. Add key once: Vercel → Project → Settings → Environment Variables
  3. Name: GEMINI_API_KEY or GROQ_API_KEY → paste value → Save
  4. Run vercel --prod --force to deploy
  5. Switch provider anytime from this Settings panel — no Vercel changes needed!
  6. Privacy: Only your preference choices are stored in browser localStorage (provider selection, ADO org name, assigned-to email). No API keys or secrets ever leave Vercel's server.

How to create an ADO PAT →
  1. Open Azure DevOps → click your Profile avatar (top right)
  2. Click User Settings → Personal Access Tokens
  3. Click New Token — set Name, Organisation, Expiry
  4. Scopes: Test Management: Read & Write + Work Items: Read & Write + Project and Team: Read
  5. Click Create → Copy the token immediately
  6. Vercel Dashboard → Project → Settings → Environment Variables
  7. Name: ADO_PAT | Value: paste token → Save → Redeploy
